# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [2.0.0] — не выпущена (тестовая сборка)

Vox переписан на C# (.NET 10, WPF) с новым дизайном VOX 2.0. Данные 1.x (история, словарь,
настройки, модели) подхватываются без переустановки.

### Added
- Фонетический поиск по словарю терминов: кривое написание модели, которого нет в словаре
  («фронтинде», «вэкенд»), заменяется на ближайший термин из группы прижившихся слов; в логе
  пометка [FUZZY].
- Поиск по звучанию для латиницы с английским словарём (SCOWL, 281 тыс. форм): «Frountent», «Bek End»,
  «Hrome», «Andreal Enjane» → «фронтенд», «бэкенд», «Chrome», «Unreal Engine». Обычные английские слова
  не трогаются (water больше не становится Wouter), кривое английское слово становится словом
  («Beautifull» → «beautiful», в логе [EN]). Слова через дефис проверяются целиком и по частям
  («Фрунтенд-дизайн», «Frountent-design» → «фронтенд-дизайн»). При равной близости побеждает более
  частый термин; английское слово ставится только при высоком сходстве и если оно частое. Первый звук должен
  совпадать («GTA Vender» не становится «GTA Finder»), короткие слова сверяются и по гласным. Словарь загружается вместе с моделью.
- Новый интерфейс в стиле Windows 11 (светлая и тёмная тема): мастер первого запуска из трёх шагов
  (язык → загрузка → «попробуйте»), настройки с историей, словарём и помощью.
- Плашка записи внизу экрана: «Слушаю…» с уровнем звука, «Распознаю…», «Вставлено», «Не расслышал».
- Выбор микрофона в настройках и подсказка «Сейчас слышу вас хорошо».
- Словарь замен в настройках (добавить / удалить).
- **Самообучение:** исправьте слово в тексте после диктовки, и Vox сразу запомнит замену
  («Запомнил: кубернетис → Kubernetes»). Запомнил не то: меню Vox в трее → «Отменить последнее
  запоминание» (или Настройки → Словарь). Обычные русские слова не запоминаются. Пароли не читаются,
  текст полей не сохраняется и не пишется в лог; выключается в «Настройки → Словарь».
- Значок в трее под светлую и тёмную панель задач, с красной точкой во время записи.
- **Продолжение фразы:** Vox смотрит, что стоит перед курсором. После запятой или слова диктовка
  продолжает предложение со строчной буквы, после точки — начинает новое, в начале поля — без
  пробела, в середине текста — без лишней точки. Если программа не показывает свой текст (Telegram
  и т.п.), Vox опирается на свою предыдущую вставку в то же окно (в течение минуты).
- **Словарь понимает падежи:** «на гитхабе» → «на GitHub», «с керилом» + замена «керил → Кирилл»
  → «с Кириллом». Самообучение сохраняет замену так, как её исправили («Лебовски → Lebowski»), и одна запись покрывает все падежи.
- Сочетания клавиш голосом: «контрол си» → Ctrl+C, «контрол шифт ти» → Ctrl+Shift+T, «альт эф
  четыре» → Alt+F4; «шифт», «энтер», «таб» пишутся как Shift, Enter, Tab. «Контроль качества» и
  другие обычные фразы не меняются.

- **IT/ИИ-словарь расширен** (~3900 терминов, ~8700 вариантов произношения; этап 2 — `docs/dictionary.md`): компании и модели
  (Anthropic, OpenAI, DeepSeek, Qwen, Mistral, Grok, Kimi, GLM), инструменты (Claude Code, Cursor,
  Codex, Windsurf, Lovable, Perplexity, NotebookLM, Manus), автоматизация (n8n, Make, Zapier, Dify,
  LangChain, CrewAI), локальный запуск (Ollama, LM Studio, llama.cpp, vLLM, GGUF, QLoRA), картинки,
  видео и звук (Midjourney, Stable Diffusion, ComfyUI, Sora, Veo, Kling, Suno, ElevenLabs, Whisper).
- «точка» перед расширением файла: «Точка MP4» → «.mp4», «index точка html» → «index.html»; «GTA Шесть» → «GTA 6».
- «на опусе версии 5.5» → «на Opus 5.5», «код-код» → Claude Code, «GPT Mage» → GPT Image.
- Модель с версией: «клод опус четыре и пять» → Claude Opus 4.5, «джипити пять» → GPT-5,
  «джемини два и пять про» → Gemini 2.5 Pro, «дипсик эр один» → DeepSeek R1 — и для GigaAM, и для Parakeet.
- «клауд», «клот», «клод» → Claude для обеих моделей, латинское «Cloud» → Claude для русской модели («Cloud Code» → Claude Code, «клаудн хром» →
  Claude in Chrome); Google Cloud, Яндекс Клауд, Cloud Run, Cloudflare не трогаются.
- Соцсети латиницей (решение владельца): YouTube, Telegram, Instagram, TikTok, VK, WhatsApp,
  Twitter, Facebook, Pinterest, Twitch, Spotify, Netflix; «VSL», «вээсэл» → WSL.
- Термины из диктовок владельца: OpenCode, OpenVid, Harness CLI, Remotion, Mixamo, vidIQ, Clipchamp,
  Hermes Agent, LongCat, GPT Image, git pull/push/commit, Google Drive / Google Диск, VPS, крипто
  (Rabby Wallet, Bitget, DeBank, DeFi, Arbitrum, MetaMask), «силай» → CLI, «закомитить» → «закоммитить».
- Многословные термины склоняются: «в докер компоузе» → «в docker-compose».

### Changed
- Удаление Vox: модели удаляются всегда, история, словарь и настройки по вопросу (тихое удаление их
  оставляет); автозапуск убирается. Обновление поверх ничего не удаляет.
- Самообучение запоминает исправление с первого раза; в меню трея есть «Отменить последнее запоминание».
  Если исправлено слово, которое Vox сам вставил из словаря (опечатка при обучении: «гитхап → GitHbu»),
  исправляется эта запись («Исправил: гитхап → GitHub»), без цепочек. Учится только то, что вы
  напечатали сами (не автозамена Word или Grammarly), слова от 3 букв; запись, которая дважды
  вернулась к прежнему написанию, закрепляется и меняется только вручную.
- Шрифт интерфейса — Golos Text (вместо Unbounded и Onest), заголовки снова обычного размера.
- Плашка «Вставлено» и «Запомнил: …» показывает знак Vox вместо значка.
- Плашка «Запомнил: …» держится 2 с (было 4); в текстах интерфейса нет длинных тире.
- **Словарь: латиницей — только названия, бренды, модели, аббревиатуры и код.** Прижившиеся
  заимствования остаются по-русски, исправляется только написание: «промт» → «промпт», «бек энд» →
  «бэкенд», «файн тюнинг» → «файнтюнинг». Убрано ~540 замен обычных слов на английские
  («промпт» → prompt, «деплой» → deploy, «юзер» → user, «хелп» → help, «тернарный» → ternary…) —
  список в `docs/terms.md`.
- Обычные слова, совпадающие с названиями (курсор, агент, опус, сонет, лама, кодекс), меняются
  только в связке: «клод опус» → Claude Opus, «курсор агент» → Cursor Agent.
- Модели при имени пользователя с русскими буквами хранятся в `C:\ProgramData\Vox\models`.
- Автозапуск — для текущего пользователя (переключается в настройках).
- Нажатия, которые Vox отправляет сам (Ctrl+V), больше не могут запустить запись.

### Fixed
- «1 600 МГ» → «1 600 МГц», «3 ГГ» → «3 ГГц» (модель теряет «ц» после числа).
- Термины по живому тесту: «Си++», «Charb++» → C++, «Masila» → Mozilla, «Smos» → CMOS, «Дирам» → DRAM,
  «Родеон» → Radeon, «Jmile» → Gmail, «Open I» → OpenAI, «Deep Seak» → DeepSeek, «LM-модели» → «LLM-модели» и др.
- Словарь терминов: «сеть оптимизм» и ещё 6 сетей писались как «сеть сеть Optimism».
- Паразит перед вводным словом не съедает запятую («в словарь, э-э, ну, не факт» → «в словарь, ну, не
  факт»), а после паразита с многоточием не остаётся «....».
- Словарь по живому логу: фронтенд, бэкенд, LLM-полировка, Python («Piton», «на питоне»), C# («Cisharp»),
  Chrome («Hrome»), саунд-дизайн.
- Латинская форма модели с заглавной посреди фразы заменяется строчным словом: «Это Frount End» →
  «Это фронтенд»; в начале предложения заглавная остаётся.
- Словарь по живому логу: «Сишар», «Сшарп», «Sisharp», «Nasisharp» → C#, «Ева Скрипт», «Javascript» →
  JavaScript, «на гоу» → «на Go», «Andreal Enjane» → Unreal Engine, «клодкот» → Claude Code,
  «Claude опуск пять и пять», «Клодопус 5,5», «Опуск 5 и пять» → Claude Opus 5.5 / Opus 5.5.
- Самообучение в Notepad++ работает и с первой диктовки после запуска: если окно занято вставкой и
  не ответило сразу, Vox читает его ещё раз.
- «Не расслышал» на плашке короче и пропадает так же быстро, как «Вставлено».
- Текст в окнах ровный: режим Ideal вместо Display (Display рвал Golos Text). Плашка оставлена
  как была (владелец: так она выглядит лучше).
- После удаления паразита между запятыми не остаётся лишней запятой: «если мы, а-а, уменьшим» →
  «если мы уменьшим».
- Самообучение срабатывает через 5 с после правки, а не через 10.
- Самообучение: правка опечатки в слове, которое Vox сам вставил из словаря («Fluxar» → «Fluxor»,
  «GitHbu» → «GitHub»), исправляет запись словаря. Раньше такую правку отбрасывала защита от
  грамматических правок. В логе теперь видна причина, по которой правка не выучена.
- Заглавная «А» посреди фразы (так GigaAM пишет протяжное «а-а» и союз «а») становится строчной, но не
  удаляется: «на Piton А новая» → «на Piton а новая». «Пункт А», «витамин А», «часть А и Б», «выбираем А.»
  в конце фразы и «А» в начале предложения остаются.
- Термин, который модель разбила на два-три слова, выучивается одной заменой («Zena Koder» → «Zencoder»).
- Notepad++: правка выучивается, даже если сразу печатать дальше; поле перечитывается до 1 с после
  вставки; в логе краткий дифф, если правка не подошла.
- Продолжение фразы: в Notepad++ и обычных полях ввода Vox читает символы перед курсором; после Enter,
  стрелок или набора текста старая вставка больше не считается контекстом (не было лишнего пробела в начале
  строки); пустое поле (Claude Desktop с вложением) — начало, с заглавной.
- Самообучение работает и в программах без UI Automation (Notepad++ и другие на Scintilla, классические
  поля ввода): текст читается через WM_GETTEXT; поля паролей не читаются. В логе видно, каким способом.
- Самообучение не запоминает правку обычного русского слова («рак» → «RAG» превращало каждый «рак»
  в RAG); такую замену можно добавить в словарь вручную.
- Обновление не выглядит как сбой: установщик сначала просит Vox закрыться, и только потом завершает
  его принудительно.
- По корпусу владельца: «апи ключами» → «API-ключами» (окончание сохраняется), «клод-код» →
  Claude Code (термины через дефис), «Клод восемнадцать плюс» больше не становится «Claude 18»,
  домены («github.com», «vox.log») не разрываются пробелом.
- Длинное тире GigaAM («—», «–») пишется дефисом: « - » между словами, «1-2» между цифрами.
- Служебный токен Parakeet «<unk>»: внутри слова и в конце короткого — это «ё» («чё», «боёк», «всё»), иначе удаляется.
- Выход из Vox больше не ждёт до 3 с, если в очереди оставалась диктовка.
- Закрытие мастера во время распаковки не оставляет мусор в папке моделей.
- Плашка не мелькает в углу экрана при первом показе; точки шагов мастера и разделители истории
  меняют цвет вместе с темой.
- Микрофоны с 32-битным PCM (WAVE_FORMAT_EXTENSIBLE) больше не дают шум вместо речи.
- Занятый буфер обмена не подвешивает Vox на ~10 с (двойные повторы).
- Самообучение не забывает правку, увиденную один раз, при перезапуске Vox (кандидаты хранятся в
  `vox_data.db`, таблица `correction_candidates`; 1.x её не видит).
- «пиф-паф» больше не становится «пиф-path», «Жан-Клод» — «Жан-Claude»: дефис — часть слова.
- Вылет при смене модели (окна Tkinter в фоновых потоках) — в 2.0 все окна в одном потоке.
- Самообучение не запоминает правку окончаний и лишних букв в собственном тексте
  («тёмные → тёмной», «блоге → логе») — раньше такая пара портила все следующие диктовки.
  Уже запомненные ложные пары удалите в «Настройки → Словарь».
- Паразиты любой длины («э-э-э», «Ааа», «м-м-м», «хммм») удаляются, а заглавная после удалённого
  паразита в начале предложения сохраняется.
- «Вокс» пишется как «Vox»; «гитхап», «Pithon», «Smart Screen» — как GitHub, Python, SmartScreen.
- Нажатие клавиши, пока модель загружается, показывает «Модель ещё загружается…», а не «Не расслышал».
- Самообучение запоминает замену, только когда вы исправили то же слово так же второй раз:
  разовая правка больше не попадает в словарь.

### Removed
- Реализация на Python (остаётся в истории и в ветке `feat/gigaam-ru`).

## [1.3.0] — не выпущена (тестовая сборка)

### Added
- Модель **GigaAM v3** (Сбер) для русского языка — модель по умолчанию. Parakeet TDT v3 остаётся для английского и других европейских языков. Выбор — в окне первого запуска и в трее.
- Нарезка длинных записей по паузам на куски до 12 с перед распознаванием.
- «500 ₽» → «500 рублей» с согласованием («1 рубль», «2 рубля»).
- Трей: «Скопировать последнюю диктовку».
- Если во время удержания клавиши нажата другая (Ctrl+C и т.п.), это сочетание клавиш — запись отменяется и ничего не вставляется.
- Двойной низкий сигнал, если диктовка не распознана; в логе — причина (нет звука / слишком тихо / модель не вернула текст) и уровень громкости.
- Тесты (`tests/`), сборка установщика в GitHub Actions.

### Changed
- После вставки Vox возвращает в буфер обмена то, что там было до диктовки.
- Распознавание и вставка выполняются в отдельном потоке, а не в обработчике клавиатуры.

### Fixed
- Длинные диктовки (15–25 с) в 21% случаев возвращали пустой текст; GigaAM падала на записях длиннее ~100 с.
- Обрезался конец последнего слова: после отпускания клавиши терялось до 250 мс звука.
- Числа: «30 шесть» → 36, «семнадцать пятьдесят четыре» → «17 54» (было «67 четыре»), «150 тысяч» больше не превращается в «150 1000», «один из» не становится «1 из».
- Микрофон переоткрывается автоматически, если перестал отдавать звук.
