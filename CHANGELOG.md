# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [2.0.0] - дата нового выпуска (первая сборка 2026-10-25)

Vox переписан на C# (.NET 10, WPF) с новым дизайном VOX 2.0. Данные 1.x (история, словарь,
настройки, модели) подхватываются без переустановки.

### Added
- Диктовка через RustDesk: если зажать клавишу в окне RustDesk, записывает Vox на этом компьютере, а
  текст доходит до удалённого. Vox на удалённом компьютере больше не включает пустую запись от клавиши,
  которую передал RustDesk (переназначенные PowerToys и AutoHotkey клавиши по-прежнему работают). В окне
  RustDesk вставка ждёт, пока RustDesk передаст буфер обмена (около 0,7 с). Vox нажимает клавиши со
  скан-кодами, как настоящая клавиатура: без них RustDesk не передавал Ctrl+V.
- Страница конфиденциальности `docs/privacy.md` (по-русски и по-английски) и правила подписи
  `docs/code-signing-policy.md`, ссылки на них в README. Нужны для заявок в SignPath и Microsoft Store.
- Настройки → Помощь → «Мои данные» → «Удалить мои данные…»: история, словарь, выученные исправления,
  названия с экрана, настройки, записи, логи, дампы падений, свои модели и автозапуск этого пользователя
  Windows, потом Vox закрывается. Общая папка моделей `C:\ProgramData\Vox` остаётся. Если что-то не
  удалилось (файл занят), Vox показывает, что осталось.
- Настройки → Основное → «Сохранять записи диктовок» (по умолчанию выключено): каждая диктовка, и пустая
  тоже, сохраняется в `%APPDATA%\vox\recordings` (WAV 16 кГц и строка в `recordings.tsv`), хранятся последние
  500 записей и не больше 300 МБ. Кнопка «Открыть папку с записями». `Vox.Replay --audio` прогоняет записи через
  выбранную модель.
- Живой тест на GigaAM: слово из смеси кириллицы и латиницы («индoint») приводится к одному алфавиту и
  проверяется по словарю; точные записи без поиска по звучанию (группа `exact`): «The Deploy» → «задеплой»,
  «сделай комет» → «сделай коммит», «запуш» → «запушь», «диплей» → «деплой», «возвращает Джейсона» → JSON,
  «через PUP» → pip, Евроскрипт, VM Studio, меджорни, MCR/MCB сервер, лод код, «Сити арбитру», «баланс на Dank»,
  сваб, Envidia, IMD Rise/АМД Райзен, Bios, «PIN D Server», «колонку GBL». Слово в начале фразы сохраняет заглавную
  перед латинской частью («Кошелёк Phantom»).
- Фонетический поиск по словарю терминов: кривое написание модели, которого нет в словаре
  («фронтинде», «вэкенд»), заменяется на ближайший термин из группы прижившихся слов; в логе
  пометка [FUZZY].
- Поиск по звучанию для латиницы с английским словарём (SCOWL, 281 тыс. форм): «Frountent», «Bek End»,
  «Hrome», «Andreal Enjane» → «фронтенд», «бэкенд», «Chrome», «Unreal Engine». Обычные английские слова
  не трогаются (water больше не становится Wouter), кривое английское слово становится словом
  («Beautifull» → «beautiful», в логе [EN]). Слова через дефис проверяются целиком и по частям
  («Фрунтенд-дизайн», «Frountent-design» → «фронтенд-дизайн»). При равной близости побеждает более
  частый термин; английское слово ставится только при высоком сходстве и если оно частое. Первый звук должен
  совпадать («GTA Vender» не становится «GTA Finder»), короткие слова сверяются и по гласным. Словарь загружается вместе с моделью.
- **Подсказки с экрана:** в момент диктовки Vox смотрит заголовки открытых окон (у браузера это активная
  вкладка) и берёт оттуда латинские названия («Superwhisper», «HAPP»,
  «Lumalabs»). Если модель написала похоже по звучанию («супервиспер», «Superwisper», «хап»), Vox пишет
  название. Названия из заголовков запоминаются (до 5000, давно не встречавшиеся забываются) в
  `screen_names.json` рядом с историей. Секреты не сохраняются: ключи API, приватные ключи, адреса
  кошельков и другие длинные склейки отбрасываются целиком, слова с цифрами не сохраняются
  вовсе. Заголовки и текст в лог не пишутся, только замена с пометкой [SCREEN]. Выключатель и кнопка
  «Очистить память названий» в «Настройки → Словарь».
  Доработки по первому живому тесту: заголовки читаются, пока модель распознаёт (без задержки);
  термин в другом регистре получает своё написание («Deepl» → DeepL, «Coin marketcap» → CoinMarketCap);
  короткое слово ловит и открытый на экране термин («Дипл» → DeepL); название, увиденное только строчными
  в адресе, пишется с заглавной («Крузаде» → Cruzade, но «cruzade.com»); рядом с английским словом
  ловится слово с пропущенными буквами («Creat Token» → Create Token, «Lazy Trasur» → Lazy Treasure);
  «Салана» → Solana. Текст поля с курсором больше не читается, и слова, которые написала сама модель
  (в том числе в заголовке чата), не считаются названиями: ошибка модели не закрепляется («Джампер» →
  jamper). Такие слова удаляются и из памяти названий. Точные записи: Пупитер → Puppeteer, Этериум →
  Ethereum, Евмос → Evmos, Аида 64 Экстрим → AIDA64 Extreme, ВДсина → VDSina, Хиро SMS → HeroSMS,
  ЕТХ → ETH, Jumper ex Change → Jumper Exchange, Vid IQ → vidIQ, Визиро → v0, «Виноль бай Версель» →
  v0 by Vercel. Третий тест: латинское слово среди латинских больше не становится русским термином
  («Stells Extra Plagin» остаётся, раньше «Плагины»), русская цель от латиницы только в своём числе;
  «.gson»/«.джейсон» после имени файла → «.json»; Джимини/Гемени → Gemini, Гиминиаргон → Gemini Argon,
  Джесон/Джей Сон → JSON, Рэбби Воллетт → Rabby Wallet, Фантом Воллет → Phantom Wallet, Пубитер →
  Puppeteer, HDmell → HTML, rast → Rust, Jumper X Change → Jumper Exchange.
- Тест на Parakeet: «нотпад плюс-плюс» больше не даёт «Notepad++ плюс-плюс»; «Сити Arbitrum» → «сети Arbitrum»
  (перед названием сети); «Термс точка Джесон» → «Термс.json» (имя с заглавной); PostgreSQL, Redis, XML, XMP,
  TypeScript, LM Studio, Hugging Face, ChatGPT, MCP, Claude Code, Firefox, «в OBS», DaVinci Resolve, DeBank,
  Claude Opus в новых записях.
- Новый интерфейс в стиле Windows 11 (светлая и тёмная тема): мастер первого запуска из трёх шагов
  (язык → загрузка → «попробуйте»), настройки с историей, словарём и помощью.
- Плашка записи внизу экрана: «Слушаю…» с уровнем звука, «Распознаю…», «Вставлено», «Не расслышал».
- Выбор микрофона в настройках и подсказка «Сейчас слышу вас хорошо».
- Словарь замен в настройках (добавить / удалить).

  («Запомнил: кубернетис → Kubernetes»). Запомнил не то: меню Vox в трее → «Отменить последнее

### Changed
- Удаление Vox: модели удаляются всегда, история, словарь и настройки по вопросу (тихое удаление их
  оставляет); автозапуск убирается. Обновление поверх ничего не удаляет. Вопрос называет папку, которую
  удалит: программа удаления работает от имени учётной записи, под которой её запустили, и если UAC
  спросил пароль администратора, данных обычного пользователя она не видит (`docs/adr/034`). Свои
  данные каждый пользователь удаляет в Vox кнопкой «Удалить мои данные».
- Самообучение запоминает исправление с первого раза; в меню трея есть «Отменить последнее запоминание».
  Если исправлено слово, которое Vox сам вставил из словаря (опечатка при обучении: «гитхап → GitHbu»),
  исправляется эта запись («Исправил: гитхап → GitHub»), без цепочек. Учится только то, что вы
  напечатали сами (не автозамена Word или Grammarly), слова от 3 букв; запись, которая дважды
  вернулась к прежнему написанию, закрепляется и меняется только вручную.
- Шрифт интерфейса — Golos Text (вместо Unbounded и Onest), заголовки снова обычного размера.
- Плашка «Вставлено» и «Запомнил: …» показывает знак Vox вместо значка.
- Плашка «Запомнил: …» держится 2 с (было 4); в текстах интерфейса нет длинных тире.
- **Словарь: латиницей — только названия, бренды, модели, аббревиатуры и код.** Прижившиеся
  заимствования остаются по-русски, исправляется только написание: «промт» → «промпт», «бек энд» →
  «бэкенд», «файн тюнинг» → «файнтюнинг». Убрано ~540 замен обычных слов на английские
  («промпт» → prompt, «деплой» → deploy, «юзер» → user, «хелп» → help, «тернарный» → ternary…) —
  список в `docs/terms.md`.
- Обычные слова, совпадающие с названиями (курсор, агент, опус, сонет, лама, кодекс), меняются
  только в связке: «клод опус» → Claude Opus, «курсор агент» → Cursor Agent.
- Модели при имени пользователя с русскими буквами хранятся в `C:\ProgramData\Vox\models`.
- Автозапуск — для текущего пользователя (переключается в настройках). Галочку установщика выполняет
  сам Vox от имени пользователя, который запустил установку, а не администратора из окна UAC.
- Нажатия, которые Vox отправляет сам (Ctrl+V), больше не могут запустить запись.

### Fixed
- «Микрофон молчит»: если от микрофона не приходит ни звука, плашка говорит об этом сразу, пока клавиша
  ещё зажата, а не «Не расслышал» после диктовки. Vox тут же открывает микрофон заново и продолжает запись:
  если звук появится, диктовка не пропадёт. Раньше после такой записи плашка ждала до 5 секунд, пока
  микрофон переоткроется.
- Выключение и перезагрузка Windows больше не выдаются при следующем запуске за сбой («previous run ended
  without a normal exit»). Сон и пробуждение компьютера тоже записываются в лог.
- Диктовка больше не теряется, если буфер обмена занят другой программой (например, RustDesk передаёт
  его на удалённый компьютер): через секунду ожидания Vox набирает текст напрямую, без буфера. Если и это
  не вышло, плашка пишет «Не вставилось» (а не «Не расслышал»), текст есть в истории и в трее
  («Скопировать последнюю диктовку»). В логе обычно видно, какая программа держала буфер. Копирование
  из трея и «Истории» при занятом буфере больше не падает: в «Истории» кнопка пишет «Буфер занят».
- История и поиск: две диктовки с одинаковым временем (до миллисекунды) идут от новой к старой, а не
  в случайном порядке.
- C# и C++ больше не путаются: «Charp» модели становится C#, а не C++ (термин с «++» подходит только слову,
  после которого модель написала «+»). «Си-++», «Si++», «C+» и «Си-плюс-плюс» становятся C++. «Beckend» рядом
  с термином («на Beckend Python») становится «бэкенд», а «CRM Bitrix» остаётся как есть.
- Обычное русское слово больше не превращается в название по звучанию: «трафик» остаётся «трафиком», а не Traefik.
- Слово, после которого модель написала «+», сравнивается с Notepad++ и C++ мягче: «Notpac+» → Notepad++.
- Слово через дефис склоняется по последней части: «LM-моделей», «элэлэм-моделей» → «LLM-моделей».
- Новые написания модели: «веб-хук» → webhook, «аппи» → API, «через Peep» → pip, «GMini» → Gemini,
  «Яндекс GPT» и «Яндекс ДжиПТ» → YandexGPT, «Хью Фейс» → Hugging Face, «Clod Discopt» → Claude Desktop,
  «Котлен» → Kotlin.
- Ещё написания модели: «The Deployd» → «задеплоить», «деплей» → «деплой», «вклад Cookbooks» → «в Claude
  Cookbooks», «Ноладж Work plagens» → Knowledge Work plugins, «Sque» и «Esquel» → SQL, «депло» → «деплой»,
  «Githab» → GitHub, «Cnolage Work Plagins» и «Nolege work plagens» → Knowledge Work plugins, «Нолэч» →
  Knowledge, «Майску», «Misqul», «Mysqua», «MicQ» → MySQL.
- Слова на «г», «к», «х» склоняются и во множественном числе на «-и»: «веб-хуки» → webhook.
- Запятая вокруг «а-а» и «э-э» остаётся, если она нужна фразе и без них: между двумя глаголами («записывал,
  появились»), после «Так» в начале предложения, после «слушай» и «смотри» и перед «если», «когда», «но»,
  «потому что», «то есть».
- Безопасность моделей (D036): архив модели сверяется с SHA-256 и размером до распаковки, а файлы модели
  сверяются перед каждой загрузкой. Подменённую или повреждённую модель Vox не загружает, в том числе модель,
  которую другой пользователь ПК положил в общую папку `C:\ProgramData\Vox\models`. Оборванная загрузка без
  `Content-Length` больше не уходит в распаковку. Уже скачанные модели заново не скачиваются.

- Паразит перед вводным словом не съедает запятую («в словарь, э-э, ну, не факт» → «в словарь, ну, не

  «Это фронтенд»; в начале предложения заглавная остаётся.
- Словарь по живому логу: «Сишар», «Сшарп», «Sisharp», «Nasisharp» → C#, «Ева Скрипт», «Javascript» →
  JavaScript, «на гоу» → «на Go», «Andreal Enjane» → Unreal Engine, «клодкот» → Claude Code,
  «Claude опуск пять и пять», «Клодопус 5,5», «Опуск 5 и пять» → Claude Opus 5.5 / Opus 5.5.
- Самообучение в Notepad++ работает и с первой диктовки после запуска: если окно занято вставкой и
  не ответило сразу, Vox читает его ещё раз.
- «Не расслышал» на плашке короче и пропадает так же быстро, как «Вставлено».
- Текст в окнах ровный: режим Ideal вместо Display (Display рвал Golos Text). Плашка оставлена
  как была (владелец: так она выглядит лучше).
- После удаления паразита между запятыми не остаётся лишней запятой: «если мы, а-а, уменьшим» →
  «если мы уменьшим».
- Самообучение срабатывает через 5 с после правки, а не через 10.
- Самообучение: правка опечатки в слове, которое Vox сам вставил из словаря («Fluxar» → «Fluxor»,
  «GitHbu» → «GitHub»), исправляет запись словаря. Раньше такую правку отбрасывала защита от
  грамматических правок. В логе теперь видна причина, по которой правка не выучена.
- Заглавная «А» посреди фразы (так GigaAM пишет протяжное «а-а» и союз «а») становится строчной, но не
  удаляется: «на Piton А новая» → «на Piton а новая». «Пункт А», «витамин А», «часть А и Б», «выбираем А.»
  в конце фразы и «А» в начале предложения остаются.
- Термин, который модель разбила на два-три слова, выучивается одной заменой («Zena Koder» → «Zencoder»).
- Notepad++: правка выучивается, даже если сразу печатать дальше; поле перечитывается до 1 с после
  вставки; в логе краткий дифф, если правка не подошла.
- Продолжение фразы: в Notepad++ и обычных полях ввода Vox читает символы перед курсором; после Enter,
  стрелок или набора текста старая вставка больше не считается контекстом (не было лишнего пробела в начале
  строки); пустое поле (Claude Desktop с вложением) — начало, с заглавной.
- Самообучение работает и в программах без UI Automation (Notepad++ и другие на Scintilla, классические
  поля ввода): текст читается через WM_GETTEXT; поля паролей не читаются. В логе видно, каким способом.
- Самообучение не запоминает правку обычного русского слова («рак» → «RAG» превращало каждый «рак»
  в RAG); такую замену можно добавить в словарь вручную.
- Обновление не выглядит как сбой: установщик сначала просит Vox закрыться, и только потом завершает
  его принудительно.
- По корпусу владельца: «апи ключами» → «API-ключами» (окончание сохраняется), «клод-код» →
  Claude Code (термины через дефис), «Клод восемнадцать плюс» больше не становится «Claude 18»,
  домены («github.com», «vox.log») не разрываются пробелом.
- Длинное тире GigaAM («—», «–») пишется дефисом: « - » между словами, «1-2» между цифрами.
- Служебный токен Parakeet «<unk>»: внутри слова и в конце короткого — это «ё» («чё», «боёк», «всё»), иначе удаляется.
- Выход из Vox больше не ждёт до 3 с, если в очереди оставалась диктовка.
- Закрытие мастера во время распаковки не оставляет мусор в папке моделей.
- Плашка не мелькает в углу экрана при первом показе; точки шагов мастера и разделители истории
  меняют цвет вместе с темой.
- Микрофоны с 32-битным PCM (WAVE_FORMAT_EXTENSIBLE) больше не дают шум вместо речи.
- Занятый буфер обмена не подвешивает Vox на ~10 с (двойные повторы).
- Диктовка, которую Vox кладёт в буфер обмена только ради вставки, больше не попадает в журнал буфера
  (Win+V) и облачный буфер. Другие программы, которые следят за буфером (RDP, виртуальные машины), видят
  её как раньше. Если «Сохранять мой буфер обмена» выключено, диктовка остаётся в буфере как
  обычная копия. «Скопировать последнюю диктовку» тоже обычная копия.
- После вставки Vox возвращает буфер обмена целиком: картинки, файлы и текст с оформлением, а не только
  простой текст. Пароль из менеджера паролей возвращается вместе с его пометкой «не хранить в журнале и
  облаке».
- Самообучение не забывает правку, увиденную один раз, при перезапуске Vox (кандидаты хранятся в
  `vox_data.db`, таблица `correction_candidates`; 1.x её не видит).
- «пиф-паф» больше не становится «пиф-path», «Жан-Клод» — «Жан-Claude»: дефис — часть слова.
- Вылет при смене модели (окна Tkinter в фоновых потоках) — в 2.0 все окна в одном потоке.
- Самообучение не запоминает правку окончаний и лишних букв в собственном тексте
  («тёмные → тёмной», «блоге → логе») — раньше такая пара портила все следующие диктовки.
  Уже запомненные ложные пары удалите в «Настройки → Словарь».
- Паразиты любой длины («э-э-э», «Ааа», «м-м-м», «хммм») удаляются, а заглавная после удалённого
  паразита в начале предложения сохраняется.
- «Вокс» пишется как «Vox»; «гитхап», «Pithon», «Smart Screen» — как GitHub, Python, SmartScreen.
- Нажатие клавиши, пока модель загружается, показывает «Модель ещё загружается…», а не «Не расслышал».
- Самообучение запоминает замену, только когда вы исправили то же слово так же второй раз:
  разовая правка больше не попадает в словарь.

### Security
- В `vox.log` больше нет текстов диктовок и того, что вы набрали сами: строки `[STT] Raw/Final`, `[CTX]`,
  `[FUZZY]`, `[EN]`, `[SCREEN]` и `[LEARN]` пишут только длину текста, число слов и правок. Тексты в лог
  можно вернуть в Настройки → Помощь → «Для разработчика» → «Писать тексты диктовок в лог» (по умолчанию
  выключено, файлом переноса не включается). Пока это включено, рядом с «Открыть логи» и в окне ошибки
  есть предупреждение. `Vox.Replay` читает тексты и из `recordings.tsv`.
- «Очистить» в истории удаляет диктовки по-настоящему: база перезаписывается (`secure_delete`, очистка
  индекса поиска, `VACUUM`, `wal_checkpoint(TRUNCATE)`), удаляются записи голоса, лог, отчёты о сбоях
  (`%LOCALAPPDATA%\vox\crashes`) и копии `vox-до-импорта-*.zip`. Таких копий хранится не больше двух.

### Removed
- Реализация на Python (остаётся в истории и в ветке `feat/gigaam-ru`).

### Security
- Сборка установщика: пакеты NuGet ставятся строго по `packages.lock.json`, Inno Setup закреплён по версии
  и SHA-256, у токена CI только нужные права, история проверяется gitleaks, Dependabot предлагает обновления.
- SHA-256 установщика видна в отчёте сборки, а не только рядом с файлом. На релизном теге CI подтверждает
  происхождение файла (`gh attestation verify vox-setup.exe --repo privatekey7/Vox`).

## [1.3.0] - не выпущена, вошла в 2.0.0

### Added
- Модель **GigaAM v3** (Сбер) для русского языка — модель по умолчанию. Parakeet TDT v3 остаётся для английского и других европейских языков. Выбор — в окне первого запуска и в трее.
- Нарезка длинных записей по паузам на куски до 12 с перед распознаванием.
- «500 ₽» → «500 рублей» с согласованием («1 рубль», «2 рубля»).
- Трей: «Скопировать последнюю диктовку».
- Если во время удержания клавиши нажата другая (Ctrl+C и т.п.), это сочетание клавиш — запись отменяется и ничего не вставляется.
- Двойной низкий сигнал, если диктовка не распознана; в логе — причина (нет звука / слишком тихо / модель не вернула текст) и уровень громкости.
- Тесты (`tests/`), сборка установщика в GitHub Actions.

### Changed
- После вставки Vox возвращает в буфер обмена то, что там было до диктовки.
- Распознавание и вставка выполняются в отдельном потоке, а не в обработчике клавиатуры.

### Fixed
- Длинные диктовки (15–25 с) в 21% случаев возвращали пустой текст; GigaAM падала на записях длиннее ~100 с.
- Обрезался конец последнего слова: после отпускания клавиши терялось до 250 мс звука.
- Числа: «30 шесть» → 36, «семнадцать пятьдесят четыре» → «17 54» (было «67 четыре»), «150 тысяч» больше не превращается в «150 1000», «один из» не становится «1 из».
- Микрофон переоткрывается автоматически, если перестал отдавать звук.
