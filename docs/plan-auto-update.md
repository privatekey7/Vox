# План: обновление Vox с GitHub по кнопке (24.10.2026, отложено)

Идея владельца. Структура одобрена, но отложена до подписи установщика (SignPath, `docs/adr/032`):
без подписи окно UAC показывает «Неизвестный издатель», а сверка SHA-256 из того же релиза защищает
только от битой загрузки, не от подмены.

## Что уже есть

- Репозиторий `privatekey7/Vox` публичный, релизы на GitHub (v1.0.0–v1.2.0), к v1.2.0 приложен только
  `vox-setup.exe`. Релизы создаются вручную.
- CI (`build.yml`) на теге `v*` собирает `vox-setup.exe` и `.sha256`, но кладёт их только в артефакт.
- `vox.iss`: тот же AppId, установка поверх сохраняет данные, `PrepareToInstall` закрывает Vox
  (событие `Local\Vox.Quit`, потом taskkill). Запуск после установки `skipifsilent`: при тихой установке
  Vox сам не стартует. Версия в `Directory.Build.props` и `MyAppVersion`.

## Как будет работать

- Проверка: при запуске и раз в сутки `GET api.github.com/repos/privatekey7/Vox/releases/latest`
  (без токена, лимит 60/час на IP), сравнение тега с версией сборки. Pre-release пропускаются.
- Уведомление в трее «Вышла Vox X.Y».
- Карточка «Обновления» в Настройках: текущая версия, «Проверить»; при новой версии номер, текст
  релиза как список изменений, кнопка «Обновить».
- «Обновить»: скачать `vox-setup.exe` во временную папку с прогрессом, сверить с `vox-setup.exe.sha256`
  из релиза (после подписи ещё проверка Authenticode-подписи и издателя), запустить
  `/SILENT /SUPPRESSMSGBOXES /NORESTART /MERGETASKS="!autostart" /RELAUNCH`. UAC один раз (установка в
  Program Files). `!autostart`: иначе тихое обновление повторит галочку установщика и включит
  автозапуск тому, кто выключил его в настройках (`docs/adr/034`).
- `vox.iss`: запуск Vox после тихой установки по ключу `/RELAUNCH`, `runasoriginaluser`
  (не от администратора, иначе хук и вставка в обычные окна ведут себя иначе). Строка не `postinstall`,
  поэтому флаг нужен явно: без него `[Run]` запускает от имени установщика. Ничего из профиля
  пользователя (HKCU, `{userappdata}`) установщик сам не пишет (`docs/adr/034`).
- Приватность: переключатель «Проверять обновления» (предложено: включён по умолчанию) с подписью,
  что Vox только узнаёт номер версии. Данные пользователя никуда не уходят.

## Выпуск релиза

- Шаг в CI на теге `v*`: создать релиз GitHub и приложить `vox-setup.exe` и `vox-setup.exe.sha256`
  (после подписи: подписанный файл). Описание релиза пишет владелец, Vox показывает его как изменения.

## Ограничения

- Работает начиная с 2.0: с 1.x обновиться один раз вручную.
- Объём: одна сессия (проверка и скачивание с тестами в Core, UI, трей, `vox.iss`, CI).
