# Англицизмы в русской диктовке: как это решают другие (23.10.2026)

Обзор 8 агентов (Sonnet, веб-поиск): диктовочные приложения (коммерческие и open source), российские
продукты, модели распознавания (закрытые и открытые), бенчмарки, механизмы подсказки терминов, статьи.
Пометки: «замер» — независимое измерение, «вендор» — заявление производителя, «оценка» — вывод без замера.

## Главное

- **Потолок задаёт модель, а не словарь.** Независимый бенчмарк 24 моделей на русской IT-диктовке
  (Хабр, [1066528](https://habr.com/ru/articles/1066528/)) меряет EPI — долю английских терминов,
  оставшихся латиницей. GigaAM v3: EPI ~41 (22-е место из 24), у нас на контрольном наборе 27/66 ≈ 41%.
  Совпадение: постобработка текста уже взяла почти всё, что можно взять из вывода v3.
- **Причина.** GigaAM учили только на русском, частые английские слова в разметке авторы сами
  заменяли кириллицей («ютуб», «смс»), универсального решения для англицизмов у них нет
  ([Сбер о GigaAM v3](https://developers.sber.ru/kak-v-sbere/culture/gigaAM-v3)). Yandex SpeechKit и T-one
  тоже пишут английские слова кириллицей.
- **Кто справляется и почему** (замер, Хабр, GPU):

| Модель | EPI | Где |
|---|---|---|
| OpenAI gpt-transcribe + prompt | ~90 | облако |
| Google Chirp 3 | ~84 | облако |
| Breeze-ASR-25 (Whisper, дообучен на zh-en code-switching) | ~83 | открытая |
| Whisper Turbo RU code-switch (coriollon) | ~80 | открытая |
| Whisper Turbo + prompt | ~78 | открытая |
| Deepgram Nova-3 | ~70 | облако |
| GigaAM v3 | ~41 | открытая, наша |

  Общее у лидеров: обучение на смешанной речи, язык на уровне токена (не фразы), алфавит с латиницей,
  подсказка терминов, которой модель обучена пользоваться (Deepgram keyterm, Soniox context, OpenAI prompt).
  Облако против open source в этом бенчмарке статистически не различается (p = 0,13).
- **Ориентир «идеально».** Ни один конкурент не показал почти 100% на RU+EN. Wispr Flow (облако + LLM) в
  единственном найденном тесте сохранил 63% английских слов (вендор-конкурент, одна запись). Тезис
  «Soniox и GPT-4o ~96%» — из того же вендорского теста, независимо не подтверждён; в code-switching
  бенчмарке AssemblyAI (без русского) GPT-4o Transcribe среди худших.

## Механизмы, которые можно взять офлайн

| Вариант | Нужно обучение | Цена на CPU | Доказательства |
|---|---|---|---|
| A. Вторая модель для фраз с термином: Whisper Turbo RU code-switch ([coriollon](https://huggingface.co/coriollon/whisper-large-v3-turbo-russian-codeswitch), CT2 int8, 782 МБ) | нет (готовая) | не мерили; Whisper на CPU медленный, но вызывать только при подозрении на термин | замер Хабра EPI ~80; карточка автора: точность терминов 12,6 → 74,3% |
| B. Поиск термина по звуку (CTC word spotting, [arXiv 2406.07096](https://arxiv.org/abs/2406.07096)) на `v3_e2e_ctc` с кириллическими вариантами произношения | нет | второй энкодер, ~+0,2 с | статья: F 0,44 → 0,87 на английском; для русского цифр нет; офлайн-реализация FluidAudio (Parakeet) |
| C. Дообучение GigaAM на синтезированных смешанных фразах (TTS) | да, один раз | 0 (та же модель) | coriollon: 2160 синтетических фраз + LoRA на Whisper; чистый русский −2 п.п.; в академии CS-дообучение даёт кратный выигрыш |
| D. Сбор названий с экрана (идея владельца): текст активного окна, память увиденных названий | нет | фоновый UI Automation | у Wispr, VoiceInk, Superwhisper, Aqua контекст экрана есть; кормит A–C списком терминов |
| E. Маленькая LLM выбирает из кандидатов | нет | 1,7–6 с на CPU (handy-companion) | наш потолок 55/64 при идеальном выборе; модели < 3B плохо слушаются (Handy) |

Не подходят: подсказки в декодере (hotwords, GPU-PB) — тот же класс, что уже сломал текст; TCPGen,
SeACo-Paraformer, CLAS — нужно обучение; Qwen3-ASR с контекстом — 0.6B портил русский, 1.7B не мерили;
Voxtral, Canary-Qwen, Granite, Fun-ASR — нет русского или нет пути на CPU.

## Что дальше (предложение координатора, решение за владельцем)

1. **Замер A** (дешевле всего, самые сильные доказательства): coriollon на тех же 30 WAV контрольного
   набора, ничего не подстраивая. Мерить: термины, порча русского, секунды на фразу на этом CPU.
   Если терминов заметно больше 27 и скорость приемлема при вызове только на фразах с термином — план
   встраивания. Приёмка только по набору №2.
2. Если A медленный: B (поиск по звуку) или C (дообучение) — C ранее отклонён владельцем как дорогой,
   но рецепт coriollon (2 тыс. синтетических фраз, LoRA) дешевле, чем казалось.
3. D делать в любом случае: список названий с экрана нужен любому из вариантов.
