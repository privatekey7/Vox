# Контрольный набор (только для координатора)

**Рабочим сессиям: не использовать эти фразы для правок словаря и правил.** Набор нужен, чтобы
честно мерить, как Vox справляется со словами, под которые его не подгоняли. Правки делаются по
`tools/eval/anglicisms-30.tsv`; этот набор только для проверки. Записи владельца (WAV) хранятся у
координатора, в репозиторий не кладутся.
