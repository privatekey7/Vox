# VOX 2.0 — дизайн-система

Утверждено владельцем 21.10.2026. Визуал сгенерирован в ChatGPT по листу айдентики
(`00-identity-sheet.jpg`); экраны `ui-*.jpg` — эталон для реализации на WPF.

## Айдентика

- **Символ** — объёмная синяя лента «V» (`assets/brand/vox-symbol.png`, прозрачный фон, 1024 px).
- **Слоган** — «SPEAK IT DONE»; надпись «VOX 2.0»: «VOX» тёмно-синим `#0B1630`, «2.0» акцентом `#0866FD`.
- **Иконка приложения** — белая плитка со скруглением ≈22% и символом (`vox-icon-light.png`);
  тёмная версия — плитка `#061223` (`vox-icon-dark.png`).
- **Значок в трее** — плоский упрощённый «V»: синий `#0A5CF0` на светлой панели задач,
  голубой `#60CDFF` на тёмной; «идёт запись» — красная точка `#FF4D4F` с белой обводкой.

## Типографика

Шрифт — системный **Segoe UI Variable** (в WPF: `Segoe UI Variable Display` для заголовков,
`Segoe UI Variable Text` для текста; запасной — `Segoe UI`).

| Роль | Размер | Насыщенность |
|---|---|---|
| Заголовок экрана («Привет! Я Vox») | 28 | SemiBold |
| Заголовок раздела («Основное», «История») | 24 | SemiBold |
| Вопрос / подзаголовок карточки | 16 | SemiBold |
| Основной текст | 14 | Regular |
| Подпись, подсказка | 12 | Regular |
| Плашка записи | 15 | Medium |

## Форма

- Скругление: окна 8, карточки 8, кнопки и поля 6, плашка записи — полностью круглая.
- Отступы окна 32, между карточками 12, внутри карточки 16–20.
- Тень карточек едва заметная; у плашки записи — мягкая `0 8 24 rgba(0,0,0,.30)`.

### Плашка записи: знак Vox (вариант B, решение владельца 22.10.2026)

- «Вставлено» и «Запомнил: X → Y» — цветной знак Vox (`assets/brand/vox-symbol.png`, рисунок не
  менять) вместо глифа: 22×22 px, отступ справа 10 px, по центру по вертикали; в приложении —
  уменьшенная копия `vox-symbol-66.png` (Lanczos, для чёткости до 300 %), `HighQuality`-масштаб.
- «Слушаю…» — красная точка + полоски + таймер, без знака; «Распознаю…», «Не расслышал»,
  «Модель ещё загружается…» — глифы, как раньше.
- Плашка: `rgba(30,38,54,.92)`, радиус 22, высота 44, отступы 0 20 0 16, текст 15 px Medium белым;
  тёмная в обеих темах.

## Ресурсы (`assets/`)

| Файл | Назначение |
|---|---|
| `icons/vox.ico` | Иконка приложения и установщика (16–256 px) |
| `icons/vox-dark.ico` | Тёмная версия (запасная) |
| `icons/tray-light.ico`, `icons/tray-dark.ico` | Значок трея для светлой / тёмной панели задач (16–64 px) |
| `icons/tray-recording-light.ico`, `icons/tray-recording-dark.ico` | «Идёт запись» для светлой / тёмной панели задач |
| `brand/*.png` | Исходники 1024 px с прозрачностью |
| `brand/vox-bg-light.jpg`, `brand/vox-bg-dark.jpg` | Фоны (волны справа, слева место под текст) |
| `installer/wizard-{100..250}.bmp`, `installer/wizard-small-{100..250}.bmp` | Картинки Inno Setup для каждого масштаба экрана: `WizardImageFile=wizard-100.bmp,wizard-125.bmp,…` |

Выбор значка трея: читать `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize\SystemUsesLightTheme`
(1 — светлая панель → `tray-light` / `tray-recording-light`, 0 — тёмная → `tray-dark` /
`tray-recording-dark`) и переключать при смене темы.
