# D036. Модели: SHA-256 архива и файлов в каталоге, файлы держатся открытыми до загрузки

**Статус:** принято 25.10.2026 (аудит безопасности, находки M1 и M2).

## Контекст

- **M2.** Архивы моделей скачивались из релиза `asr-models` репозитория k2-fsa/sherpa-onnx без проверки
  хеша. Размер сверялся, только если сервер прислал `Content-Length`. Релиз общий и изменяемый: ассет можно
  перезалить под тем же именем. §6.2 стандарта требует проверять SHA-256 загрузок, особенно моделей.
- **M1.** sherpa-onnx на Windows не открывает файлы по путям с не-ASCII символами, поэтому у пользователей с
  кириллицей в имени профиля модели лежат в `%ProgramData%\Vox\models` (`AppPaths.Models`). В `C:\ProgramData`
  любой пользователь может создавать папки и файлы. Другой пользователь ПК мог заранее положить туда свою
  модель: Vox считал модель установленной по наличию `tokens.txt` и загружал её. Модель печатает текст в
  окна пользователя, а её файлы разбирает нативный onnxruntime.

## Решение

1. **Пины в каталоге.** У каждой модели в `ModelCatalog` есть `Archive` (размер и SHA-256 архива) и `Files`
   (размер и SHA-256 каждого файла, который грузит sherpa-onnx: encoder, decoder, joiner, tokens; у Qwen3 три
   файла папки `tokenizer`). Значения сверены с digest ассетов в GitHub API и с архивами, скачанными
   25.10.2026. Алгоритм назван в имени поля (`Sha256`), поэтому смена алгоритма видна в коде.
2. **Скачивание (`ModelDownloader`).**
   - Хеш считается по ходу записи (`IncrementalHash`). Размер сверяется с пином всегда, даже без
     `Content-Length`; лишние байты обрывают загрузку сразу, чтобы не забить диск.
   - Архив открыт с `FileShare.None` и `DeleteOnClose`: его никто не подменит между проверкой и распаковкой,
     и он исчезнет, даже если Vox закроют посреди загрузки. Распаковка идёт из того же потока.
   - При несовпадении архив удаляется, пользователь видит понятное сообщение (`ModelIntegrityException`).
   - После распаковки файлы во временной папке сверяются с пинами `Files`, и только потом папка
     переносится на место.
   - Установленная модель пропускается, только если её файлы совпадают с пинами. Папку, которая не прошла
     проверку, Vox удаляет до загрузки; если удалить нельзя (файлы другого пользователя), он так и говорит.
3. **Загрузка (`SpeechRecognizer` → `ModelFiles.OpenVerified`).**
   - Перед каждой загрузкой каждый файл открывается только на чтение с `FileShare.Read`, проверяются размер и
     SHA-256. Файлы остаются открытыми, пока sherpa-onnx их читает. Пока они открыты, Windows не даёт ни
     записать в них, ни переименовать или удалить их и любую папку над ними (проверено тестом). Значит,
     между проверкой и загрузкой модель не подменить.
   - Если файл уже открыт кем-то на запись, открыть его так не выйдет, и модель не загружается.
   - В общей папке (`%ProgramData%`) файл, до которого путь идёт через junction или символическую ссылку,
     отвергается (`GetFinalPathNameByHandleW`): ссылку в чужой родительской папке можно перенаправить после
     проверки. В своей папке `%APPDATA%` ссылки разрешены: туда пишет только сам пользователь, а кто-то мог
     перенести папку на другой диск ссылкой.
   - Проверка идёт для любой папки моделей, не только общей: так один путь кода работает у всех, а заодно
     ловится порча файлов. Цена: около 0,3 с на GigaAM (230 МБ) и около 0,9 с на Parakeet (670 МБ) при
     загрузке модели, которая и так занимает несколько секунд.
4. **ACL не трогаем.** Своя папка `models\<SID>` с закрытым DACL не спасает, если другой пользователь
   создал `C:\ProgramData\Vox` первым: он владелец родителя. Надёжный ACL требует создавать папку установщиком
   (`[Dirs]` с `Permissions:`), а это отдельная задача. Пины с открытыми файлами закрывают подмену при любом
   владельце папок, а общая папка по-прежнему одна на всех пользователей с кириллицей: модель скачивается
   один раз.

## Последствия

- Уже скачанные модели не скачиваются заново: файлы из тех же архивов совпадают с пинами (проверено на
  установленной GigaAM). Модель, распакованная из другой версии архива, при первом запуске не пройдёт
  проверку, Vox удалит её и предложит скачать снова.
- Если k2-fsa перезальёт архив под тем же именем, Vox откажется его ставить, пока пины не обновят. Новая
  версия модели означает новые пины в `ModelCatalog` (сверить с digest в
  `gh api repos/k2-fsa/sherpa-onnx/releases/tags/asr-models`).
- Пины TOFU: источник у них тот же, что и у файла. От подмены уже на момент пина они не защищают, от
  подмены после него защищают.
- **Остаётся (DoS, не подмена).** Другой пользователь может заранее создать в общей папке папку модели или
  ссылку, которую Vox не может удалить. Тогда модель не установится, Vox покажет сообщение с путём, а
  удалить папку сможет администратор. Закрыть это может установщик, если создаст
  `{commonappdata}\Vox\models` с правами, где у Users нет права удалять вложенное.
