# D038. Обновления: только уведомление о новой версии, без скачивания и установки

**Статус:** принято 15.11.2026 для релиза 2.1.0. Вторая часть (обновление по кнопке) отложена до подписи
установщика, см. `docs/plan-auto-update.md` и D032.

## Контекст

- Vox 2.0 о новых версиях не узнаёт. Пользователь остаётся на старой сборке, пока сам не зайдёт на GitHub.
- Полный план (`docs/plan-auto-update.md`): Vox сам скачивает `vox-setup.exe` и запускает его. Установщик пока
  не подписан (D032): окно UAC показывает «Неизвестный издатель», а SHA-256 из того же релиза защищает от
  битой загрузки, но не от подмены. Программа, которая сама скачивает и запускает неподписанный файл с правами
  администратора, становится удобной целью: достаточно подменить релиз или ответ сервера.
- Главный посыл Vox: «данные никуда не уходят». Любой новый выход в сеть должен быть виден пользователю,
  объяснён и выключаем.

## Решение

1. **Только узнать номер версии.** Один запрос `GET https://api.github.com/repos/privatekey7/Vox/releases/latest`
   без токена, с `User-Agent: Vox/<версия>` и `Accept`. Больше ничего: ни файлов релиза, ни текста изменений,
   ни других адресов. Vox ничего не скачивает и не запускает.
2. **Что считается новой версией.** Тег строго вида `vX.Y.Z` (без ведущих нулей), сравнение по числам
   (SemVer: 2.10.0 новее 2.9.0). Всё остальное значит «ответа нет», и пользователь ничего не видит: тег другого
   вида (в репозитории есть релиз `models-1` с зеркалом моделей), черновик, pre-release, ошибка сети, таймаут
   10 с, любой код HTTP кроме 2xx (403 и 429: лимит GitHub 60 запросов в час на IP), ответ больше 1 МБ, не JSON.
   В лог пишется только причина (`[UPDATE] No answer: http 403`), ничего из ответа и ничего о пользователе.
3. **Когда.** Через 30 с после запуска (модель уже загружена, старту ничего не мешает) и дальше раз в сутки.
   Время последнего ответа GitHub хранится в `config.json` (`update_checked`): десять перезапусков за день дают
   один запрос. Без ответа повтор через час. Запрос идёт в пуле потоков, не в потоке интерфейса.
4. **Как сообщаем.** Уведомление в трее «Вышла Vox X.Y.Z» один раз на версию (`update_notified` в
   `config.json`); строка «Вышла Vox X.Y.Z» в меню трея до перезапуска; карточка «Обновления» в «Помощи» с
   кнопками «Проверить» и «Открыть страницу загрузки». Кнопка «Проверить» работает и при выключенной
   настройке: это явное действие пользователя.
5. **Что открываем.** Только `https://github.com/privatekey7/Vox/releases/tag/vX.Y.Z`. Адрес Vox строит сам из
   проверенного тега, `html_url` из ответа не читается вовсе. Перед запуском браузера адрес ещё раз
   проверяется (`UpdateChecker.IsReleasePage`): строка сравнивается как есть, без `..`, параметров и других
   путей. Так ответ сети не может запустить другую программу или открыть чужой сайт.
6. **Настройка.** «Проверять обновления» (`check_updates`), по умолчанию включена, в том числе для
   `config.json` от Vox 2.0, где поля нет. Подпись говорит, что Vox только узнаёт номер версии. Настройка, как
   и `update_checked` с `update_notified`, не попадает в файл переноса: выходить ли в сеть, решают на каждом
   компьютере отдельно.
7. **Где код.** Разбор ответа, сравнение версий, расписание и «уже сообщали» в `Vox.Core.Updates`
   (`UpdateChecker`, `UpdateSchedule`), тесты без сети с подставным `HttpMessageHandler`. Таймер, трей и окно в
   `Vox.App` (`UpdateWatcher`, `TrayController`, `SettingsWindow`).

## Последствия

- Vox теперь выходит в сеть не только за моделью. Это описано в `docs/privacy.md`: что уходит (название и
  версия программы, IP видит GitHub) и как выключить.
- По умолчанию включено: пользователь, который ничего не менял, раз в сутки делает запрос к GitHub. Это цена
  того, что люди узнают об исправлениях. Отказ один переключатель.
- Если релиз `models-1` (или любой не `vX.Y.Z`) станет на GitHub «последним» (latest), уведомления молча
  перестанут приходить. При выпуске такого релиза его нужно создавать с `make_latest=false`.
- За общим IP (офис, VPN) лимит 60 запросов в час может быть исчерпан другими: проверка молча повторится
  через час.
- Обновление по-прежнему ставит сам пользователь: скачивает установщик со страницы релиза и запускает его.

## Отклонено

- **Скачать и запустить установщик сейчас.** До подписи (D032) это небезопасно, см. «Контекст».
- **Показывать текст релиза как список изменений.** Это чужой текст из сети в окне Vox; для уведомления он не
  нужен, страница релиза показывает его сама.
- **Проверка без настройки или выключенная по умолчанию.** Без настройки нельзя отказаться, а выключенную почти
  никто не включит, и об исправлениях не узнают.
- **Свой сервер обновлений или готовая библиотека (Squirrel, Velopack).** Лишняя инфраструктура и зависимость
  ради одного числа; GitHub уже хранит релизы.
