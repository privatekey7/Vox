# D037. Модели скачиваются из своего релиза-зеркала на GitHub

**Статус:** принято 15.11.2026. Дополняет D036: пины остаются, меняется источник архивов.

## Контекст

- Vox 2.0 качал архивы моделей из релиза `asr-models` репозитория k2-fsa/sherpa-onnx. Релиз чужой и
  изменяемый: ассет можно перезалить под тем же именем (об этом риске сказано в D036).
- 07.11.2026 так и случилось: `sherpa-onnx-nemo-parakeet-tdt-0.6b-v3-int8.tar.bz2` заменён, у него другие
  размер и SHA-256, веса encoder, decoder и joiner другие. Vox отказывался ставить архив (сверка D036
  сработала как задумано), и новые пользователи не могли скачать модель для английского.
- GigaAM в том же релизе пока совпадает с пином, но зависит от той же случайности.
- Старые файлы Parakeet, с которыми вышел Vox 2.0 и на которых мерилось качество, есть у владельца и на
  Hugging Face (`csukuangfj/sherpa-onnx-nemo-parakeet-tdt-0.6b-v3-int8`, ревизия `2bda32ec70b0`).
- В `docs/privacy.md` и `docs/code-signing-policy.md` обещано, что Vox ходит в сеть только на GitHub.

## Варианты

| Вариант | Плюсы | Минусы |
| --- | --- | --- |
| Обновить пины под новый архив k2-fsa | Одна правка | Другие веса: качество не мерилось, у всех, кто уже скачал модель, она скачается заново. При следующей перезаливке сломается снова |
| Качать пофайлово с Hugging Face по закреплённой ревизии | Ревизия неизменяема | Второй хост в сети (правка политики конфиденциальности), новый код загрузки без архива |
| **Свой релиз-зеркало в `privatekey7/Vox`** | Файлы под нашим контролем, тот же хост и тот же код загрузки, старые веса | Нужно самим выкладывать архив при смене модели, мы раздаём чужие файлы (лицензии это разрешают) |

## Решение

1. **Релиз `models-1`** в `privatekey7/Vox` («Speech models (mirror)») хранит архивы моделей приложения:
   - GigaAM v3: архив из релиза k2-fsa без изменений (SHA-256 совпал с пином D036);
   - Parakeet TDT 0.6b v3: архив собран заново из старых файлов. Каждый файл сверен с пинами `Files` в
     `ModelCatalog` и с ревизией `2bda32ec70b0` на Hugging Face. Формат тот же: `tar.bz2`, внутри папка
     `sherpa-onnx-nemo-parakeet-tdt-0.6b-v3-int8`.
2. **`ModelCatalog`**: `Url` моделей приложения указывает на зеркало (`VoxMirror`), пин архива Parakeet
   новый (другая упаковка), пины файлов прежние. Тест
   `App_models_are_downloaded_from_the_Vox_mirror_release` не даёт вернуть чужой источник.
3. **Ассеты релиза не заменяются.** Новая модель или новая версия модели выкладывается в новый релиз
   (`models-2`), `VoxMirror` и пины меняются вместе. Так уже выпущенные версии Vox продолжают качать свои
   файлы.
4. **Тег без `v`.** На теги `v*` срабатывает сборка установщика и правило защиты тегов. Релиз создан с
   `--latest=false`, поэтому `releases/latest` по-прежнему ведёт на установщик.
5. **Запасного источника нет.** Старый адрес для Parakeet отдаёт уже не тот файл, а для GigaAM он на том
   же хосте, что и зеркало: если недоступен GitHub, недоступны оба. Второй адрес добавил бы код и
   проверки без пользы.
6. **Qwen3-ASR** (только для `tools/Vox.Replay`, в приложении не предлагается) остаётся на релизе k2-fsa:
   879 МБ в зеркале не нужны, а его перезаливку заметит та же сверка.
7. **Лицензии.** GigaAM v3: MIT (SaluteDevices, текст лицензии лежит в архиве). Parakeet TDT 0.6b v3:
   CC-BY-4.0 (NVIDIA). Обе разрешают распространение. Источники, лицензии и SHA-256 указаны в описании
   релиза.

## Последствия

- У тех, кто уже скачал модели, ничего не перекачивается: пути и пины файлов не изменились.
- Новые пользователи снова могут скачать Parakeet, и это те же веса, что были в Vox 2.0.
- Vox 2.0.0 по-прежнему качает со старого адреса: в нём Parakeet не скачается, пока пользователь не
  обновит Vox. GigaAM там работает, пока k2-fsa не заменит и его.
- Пины для зеркала уже не TOFU: файлы выложены нами и сверены до загрузки. Сверка D036 остаётся и
  защищает от подмены ассета, например при краже доступа к репозиторию.
- Как выложить новую модель: собрать `tar.bz2` с папкой модели внутри, создать релиз
  `gh release create models-N --target main --latest=false`, сверить `digest` ассетов
  (`gh api repos/privatekey7/Vox/releases/tags/models-N`), обновить `VoxMirror` и пины, прогнать тесты
  `Category=Models`.
