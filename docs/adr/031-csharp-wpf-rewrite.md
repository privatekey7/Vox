# D031. Vox 2.0 на C# (.NET 10) + WPF

**Статус:** принято владельцем 21.10.2026; реализовано в ветке `csharp`.

## Контекст

- Python-версия держалась на PyInstaller, Tkinter-окнах в фоновых потоках и сторонних
  библиотеках для клавиатуры и буфера (`keyboard`, `pyperclip`). Версия 1.3.0 закрывалась без
  сообщения при смене модели из трея (вероятная причина — Tkinter-окно, созданное и удалённое
  сборщиком мусора в разных потоках; лог для подтверждения утерян).
- Vox работает только под Windows; распознавание уже было на C++ (sherpa-onnx), Python лишь
  передавал звук.

## Решение

- C# / .NET 10 LTS, WPF с темой Fluent; дизайн — айдентика VOX 2.0 (`docs/design/v2`).
- Решение из трёх проектов: `Vox.Core` (переносимая логика + тесты на Linux), `Vox.Engine`
  (sherpa-onnx), `Vox.App` (Windows).
- Перехват клавиши — собственный WH_KEYBOARD_LL-хук на отдельном потоке; микрофон — NAudio WASAPI;
  трей — H.NotifyIcon.Wpf; история — Microsoft.Data.Sqlite (та же схема, что в 1.x).
- Поведение текстовой обработки перенесено один в один: 5706 реальных диктовок из лога владельца
  дают в C# тот же результат, что в Python.

## Последствия

- Установщик ~55 МБ (self-contained .NET), зато .NET у пользователя не нужен.
- Окна, хук и микрофон собираются на Linux, но проверяются только на Windows — первая тестовая
  сборка проверяется владельцем вручную.
- `WasapiCapture` помечен в NAudio 3 устаревшим; переход на `WasapiRecorder` — после проверки на
  реальных машинах (`debt:` в `AudioCapture.cs`).
