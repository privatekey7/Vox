## Роль координатора

- Владелец (privatekey7) общается с координатором: тестирует сборки на Windows, присылает
  `vox.log` и решения. Координатор разбирает логи, согласует с владельцем план и передаёт задачи
  **рабочей сессии** (`send_message`), проверяет её результат и прогоняет регрессию.
- Код пишет рабочая сессия. Координатор сам код не правит (кроме документов), чтобы не было
  одновременных правок.
- Задачи рабочей сессии передавать только после согласования с владельцем («сначала план, потом
  действия»). Мелкие правки терминов по живым логам можно передавать сразу.
- Следить за контекстом рабочей сессии (`get_session` → `context_usage`); на ~40% — смена по
  `CLAUDE.md`.

## Открытые вопросы к владельцу

1. **Хезитация «А»** (коммит 97e05e3: удаляет заглавную «А» посреди фразы). Прогон на корпусе
   владельца (2266 диктовок): 3 срабатывания, все ложные, верных 0 —
   «Да, выбираем А.» → «Да, выбираем.»; «про часть А и Б» → «про часть и Б»;
   «была на Piton А новая на C#» → «на Piton новая на C#» (это союз «а»).
   Предложены варианты: **А** — не удалять, а делать строчной («пользователь а говорит»,
   «на Python а новая»); **Б** — убрать правило. Координатор рекомендует **А**. Ответа ещё нет.
2. **Hotwords**: эксперимент сделан (`tools/hotwords-experiment/README.md`, ADR D033):
   медленнее на 40–80%, при сильных подсказках ломает текст, при слабых пользы почти нет.
   Рекомендация: не включать; вернуться, только если владелец даст 10–20 живых WAV с терминами.
   Владельцу сообщено, явного решения нет.
3. **SmartScreen** (ADR D032): владельцу объяснено, что SignPath с малой аудиторией вероятно
   откажет, а Microsoft Store требует проверить, доступна ли регистрация из России

## Как разбирать логи владельца

- Лог владелец прикладывает в чат (`vox.log`, ~1,6 МБ, личные тексты — в репозиторий и в другие
  сессии не передавать, только выводы).
- Свежая часть: `tr -d '\r' < vox.log | grep -n 'started at' | tail` и дальше
  `grep -vE '\[CLIP\]|\[DB\]|\[PASTE\]'`. Важные строки: `[STT] Raw/Final`, `[CTX]`, `[LEARN]`,
  `peak` (норма 5–20 тыс.).
- Регрессия: вытащить Raw (`sed -n 's/.*Raw: "\(.*\)"$/\1/p'`), сделать `Raw<TAB>Raw`, прогнать
  `dotnet run -c Release --project tools/Vox.Replay -- [--model parakeet] файл.tsv` на двух
  коммитах (git worktree) и сравнить построчно. `.NET 10`: `apt-get update && apt-get install -y
  dotnet-sdk-10.0`.
