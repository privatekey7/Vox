# Склонение словарных замен

Владелец (22.10.2026): «на гитхабе» → «на GitHub», «с керилом» + «керил → Кирилл» → «с Кириллом».
Код — `src/Vox.Core/Text/Declension.cs`, тесты — `tests/Vox.Core.Tests/DeclensionTests.cs`.

## Как работает

- Склоняется кириллическое слово от 4 букв (встроенный `terms.json` и пользовательский словарь);
  у многословных источников встроенного словаря — последнее слово («в докер компоузе» →
  «в docker-compose», «гитхаб экшенсах» → «GitHub Actions»). Формы короче 5 букв не берутся.
- Замены идут одним проходом по словам, самая длинная фраза — первой («клод опус» раньше «клод»).
  Дефис — часть слова: «пиф-паф» и «Жан-Клод» не трогаются.
- Окончания по последней букве слова: согласная — а, у, ом, е, ы, ов, ам, ами, ах; -а/-я — ы, и,
  е, у, ой, ою, ам, ами, ах (ям, ями, ях); -ь — я, ю, ем, и, ей, е (ям…); -й — я, ю, ем, е, ев, и (ям…).
- Цель латиницей — окончание отбрасывается («гитхабом» → «GitHub»). Цель кириллицей — окончание
  переносится, если у цели тот же тип основы («керилом» → «Кириллом»), иначе слово не трогается.
- Самообучение сохраняет пару в начальной форме («керила → Кирилла» → «керил → Кирилл»,
  «гитхабе → GitHub» → «гитхаб → GitHub»): одна запись на все падежи.
- Порядок конвейера не изменился; числа и валюта не задеты (тест `Numbers_and_currency_are_untouched`).

## Защита от совпадений с обычными словами

Все падежные формы терминов сверены с частотными словарями русского языка
[hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords) (2018, ru): `ru_50k` и
`ru_full` (слова с частотой ≥ 5, ~393 тыс.). Словари в репозиторий не добавлены (лицензия CC BY-SA),
результат — список исключений `src/Vox.Core/Text/Data/no-declension.json` (83 форм).

- `ru_50k`: 14 совпадений, все исключены (например, «продам» ← прод → prod, «войду» ← войд → void,
  «контроле» ← контрол → Ctrl, «Джейсона» — имя).
- `ru_full`: ещё 193 совпадения, просмотрены вручную. Исключены обычные слова и имена (призма,
  ласты, лайка, редиса, статика, эластика, Кассандра, Эдита, Девин…). Оставлены формы, которые и
  есть термин в речи разработчика: «докера», «юзера», «роутера», «админа», «стека», «пайтона» и т.п.
- После исключений ни одно из 50 000 частых слов не меняется из-за склонения. Оставшиеся
  изменения этих слов были и раньше — это основные формы терминов (18 шт.:
  джейсон, эмбер, пейдж, дженкинс, кассандра, юнион, свифт, бранч, пэйдж, секьюрити, стринги, стейт, спринг, жан-клод, гэтсби, пиф-паф, джанго, девин).

## Ограничения

- Регрессия на корпусе реальных диктовок прогоняется локально (логи личные, в облако не попадают):
  `dotnet run --project tools/Vox.Replay -- --diff vox.log` печатает Raw, Final из лога и новый
  Final там, где они разошлись (`--model parakeet`, `--dict словарь.tsv` — по необходимости; без
  `--diff` — все пары Raw→Final; вход — `vox.log` или строки `Raw[<TAB>Final]`).
- Это набор окончаний, а не морфологический анализатор: прилагательные, глаголы и
  нерегулярные формы не распознаются; беглые гласные («Павел → Павла») не учитываются.
