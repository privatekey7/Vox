# План: дообучение GigaAM v3 под англицизмы + общий словарь (23.10.2026, на согласование)

Почему: потолок задаёт модель (EPI GigaAM v3 ~41%, у нас 27/66), постобработка его не поднимет,
Whisper на CPU 8 с на фразу (`docs/research-anglicisms-2026-10.md`). Дообучение — единственный путь, где
модель сама пишет термины латиницей, а скорость и размер в приложении остаются прежними.

## Что уже известно (проверено)

- **Латиница в модели есть:** в `tokens.txt` модели приложения 85 латинских токенов из 1025, все буквы
  a–z и A–Z. Расширять словарь не нужно, `tokens.txt` и sherpa-onnx не меняются. Термины пишутся почти
  по буквам (`GitHub` → `▁G i t H u b`): модель может, её не учили.
- **Код обучения официальный:** [`train_utils/`](https://github.com/salute-developers/GigaAM/tree/main/train_utils)
  (PyTorch Lightning, `torchaudio` RNNT loss, `v3_e2e_rnnt` напрямую, манифест `path/duration/transcription`,
  `--freeze_encoder_epochs`, bf16). Пример репозитория: ~170 ч, 3 эпохи, минуты на эпоху на 2 GPU.
- **Экспорт обратно:** тот же скрипт, которым собрана модель приложения:
  [`sherpa-onnx/scripts/nemo/GigaAM/export-onnx-rnnt-v3-punct.py`](https://github.com/k2-fsa/sherpa-onnx/tree/master/scripts/nemo/GigaAM),
  `gigaam.load_model("<ckpt>")` вместо имени модели, int8 только энкодер.
- **Урок coriollon** (Whisper, TTS Silero, 53 термина, 5 голосов): на голосе владельца сырой вывод ~33%
  вместо обещанных 74%. Ломается обобщение по трём осям: мало терминов, мало голосов, мало шаблонов.

## Данные

- **Термины:** `brands.txt` + `terms.json` (~1000). 15% терминов целиком в held-out (по правилу, хеш
  имени), их не будет в обучении: проверка, учится ли модель писать латиницей вообще, а не 1000 слов.
- **Фразы:** LLM генерирует 15–30 разных фраз на термин (команды, чаты, код-ревью, заметки), 20% фраз с
  2–3 терминами. Пара на фразу: `spoken` для синтеза («залей на гитхаб», 2–3 варианта произношения)
  и `label` для обучения («Залей на GitHub.»), метка в стиле вывода v3 (заглавные, пунктуация, числа).
- **Голоса:** TTS с лицензией, разрешающей обучение (ESpeech F5-TTS и Qwen3-TTS или CosyVoice3: Apache;
  Silero нельзя, CC BY-NC). 300+ голосов клонированием по коротким образцам из открытых корпусов.
  Шум, реверберация, кодек, скорость 0,9–1,1.
- **Против забывания русского (70–80% данных):** Russian LibriSpeech, SOVA RuDevices (CC-BY-4.0),
  ToneBooks (Apache). Метки ставит сама исходная `v3_e2e_rnnt` (самодистилляция), чтобы не уехал стиль.
- **Записи владельца, логи, история в облако не уходят.** Оценка на них только локально на CPU.

## Этапы и пороги (каждый шаг — решение владельца)

1. **Подготовка (локально, Claude):** список терминов и held-out, генерация фраз (агенты Sonnet),
   скрипты синтеза, манифестов и обучения в `tools/finetune/`.
2. **Пилот (1 сеанс Kaggle, ~12 ч T4):** 150 терминов, ~3 тыс. фраз (~5 ч синтеза) + ~20 ч русского.
   Сначала замороженный энкодер, затем полный с lr 1e-5–2e-5. Экспорт в ONNX.
   Проверка локально: записи anglicisms-30 (WAV есть в архиве владельца, сначала сверить с
   `anglicisms-30.tsv`), held-out термины, русский WER на открытом наборе, скорость.
   **Порог:** заметный прирост терминов на живом голосе, русский WER не хуже +0,5 п.п., скорость та же.
   Не прошёл — разбор и стоп, не масштабировать.
3. **Полный прогон:** все термины, 25–40 тыс. фраз, 60–100 ч синтеза. GPU: Kaggle, несколько сеансов.
4. **Приёмка:** новый контрольный набор №2 (владелец записывает 30 фраз с новыми терминами, включая
   held-out); регрессия по истории владельца через Replay; русский WER. Сравнение с базой 27/66 и с
   потолками шагов 2 (33) и Whisper (39).
5. **Встраивание:** новая версия модели в `ModelVersions`, пересмотр правил `FuzzyTerms` (модель сама
   пишет латиницу: часть правил может стать лишней или вредной), скачивание модели как сейчас.

## Что нужно от владельца

- Аккаунт Kaggle с подтверждённым телефоном (из РФ по отзывам то проходит, то нет). Intern-AI ненадёжен
  (с сентября 2026 даёт в основном токены API, вход через +86/WeChat). Платный запасной: RTX 4090 на
  Vast.ai/RunPod, ~$25–50 на всё, оплата из РФ сложная.
- Согласие на этапы 1–2 (пилот), дальше по результату.

## Общий словарь от всех пользователей (идея владельца, отдельная задача после пилота)

Пары «как модель услышала → как надо» («вистер» → Whisper) от многих пользователей.
- **Что отправлять:** только пары «кириллица → латиница» из личного словаря, без истории и диктовок,
  по кнопке «Обновить словарь», с показом того, что уйдёт. Русские пары («бокс → Vox») не отправлять.
- **Защита:** пара попадает в общий словарь только от N разных пользователей (например ≥ 3); латинская
  сторона похожа на бренд/термин; проверка на корпусах на ложные замены, как сейчас; привязка к версии
  модели (искажения у каждой модели свои).
- **Сервер:** минимально Cloudflare Workers + D1 (бесплатный тариф): приём пар, подсчёт, раз в сутки
  общий файл; приложение скачивает его по кнопке. Без сервера: файл в GitHub Releases, сбор вручную.
- **Польза для дообучения:** реальные искажения и реальные термины пользователей — лучший список
  терминов для следующего прогона.
