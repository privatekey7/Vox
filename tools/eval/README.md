# Набор «30 фраз с англицизмами»

`anglicisms-30.tsv`: эталон (`expected`) и Raw моделей GigaAM v3 и Parakeet v3 на записях владельца
(22.10.2026, ноутбук, тестовые фразы, не личные). Сами WAV в репозиторий не кладутся: они у
координатора, который прогоняет `Vox.Replay --audio` и считает термины.

Как мерить правки текста без звука: Raw → `Vox.Replay` (TSV `Raw<TAB>Raw`) → сравнить Final с
`expected` по терминам (список терминов на фразу — в `score-terms.py`, `K`). На 22.10:
GigaAM 48/64, Parakeet 44/64, Qwen3-ASR 0.6B 34/64.
